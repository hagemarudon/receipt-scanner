## 元に戻す方法 (ロールバック)

インストールしていないので、**フォルダを消せば完全に元どおり**。レジストリやシステムは変更しない。

| 状況 | やること |
| --- | --- |
| 起動しない・ウイルス対策ソフトに止められる | 使わずにフォルダを削除。エラー表示を控えてシステム担当に相談 |
| 新しい版で不具合 | 新しいフォルダを消し、前の版のフォルダ (`ScanText_v1.0.0` などの名前で残しておく) に戻す |
| 結果の誤りが多くて使えない | 使用をやめる。出力済みのファイルは各自の保存先にあるので、必要なら手で削除 |

### やめる・戻す判断の基準 (導入前に決めておく)
- 起動しない、または**画面が固まって閉じられない**ことが 1 回でもある
- 電子カルテの動作が**少しでも重くなる・おかしくなる**
- 印刷物の結果で、目で見て**明らかな誤りが 1 ページに数か所以上**ある書類が大半
- 元のスキャン画像が消えた・書き換わった (起きないはずだが、起きたら即中止)
