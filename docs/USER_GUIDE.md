# スキャン文字起こし 使い方

スキャンした書類の文字を読み取って、ファイルに保存するソフトです。
**インターネットにはつながりません。** 読み取った内容が外に出ることはありません。

---

## 1. 起動する

デスクトップの **ScanText** をダブルクリックします。
(ショートカットがないときは `C:\ScanText\ScanText.exe`)

## 2. 書類を読み取る

1. **書類を入れる** — 「ファイルを追加…」で選ぶか、ファイルを一覧にドラッグします
   - フォルダの中身をまとめて読むときは「フォルダを追加…」
   - 読めるファイル: JPG・PDF (ほかに PNG・TIFF・BMP)
2. **保存の形式を選ぶ** (右上の「保存する形式」の 3 つの札から 1 つを押す)

   | 選ぶもの | こんなときに | 開くソフト |
   | --- | --- | --- |
   | テキスト (.txt) | 文章をそのまま使いたい | メモ帳 |
   | 表 (.csv) | 検査結果など、表になっている書類 | Excel |
   | PDF (.pdf) | 元の見た目のまま、文字を検索・コピーできるようにしたい | PDF ビューア |

3. **「文字起こしを開始」** を押します
4. 一覧の「状態」が **完了** になったら終わりです

## 3. 結果を見る・使う

- 一覧のファイルを**クリック**すると、下の「文字起こし結果」に読み取った文字が出ます
- **コピー** → 電子カルテなどに貼り付けられます
- **保存したファイルを開く** / 一覧で**ダブルクリック** → 保存したファイルが開きます
- **保存先フォルダを開く** → 保存した場所が開きます

> **必ず元の書類と見比べてから使ってください。**
> 機械の読み取りなので、「1 と l」「0 と O」、似た漢字などを間違えることがあります。
> **手書きの文字はほとんど読めません。**

## 4. 保存される場所と名前

- いつもは**元のファイルと同じフォルダ**に、同じ名前で保存されます (例: `紹介状.jpg` → `紹介状.txt`)
- 決まったフォルダに保存したいときは、「保存先」で「指定」→「参照…」
- 同じ名前のファイルがあっても**上書きしません**。`紹介状 (2).txt` のように別の名前になります
- PDF を PDF で保存すると `紹介状_文字起こし.pdf` になります (元の PDF はそのまま)

## 5. よく使う設定

| 項目 | 使い分け |
| --- | --- |
| PDF の中身 | ふだんは「元の画像＋文字」。文字だけの PDF がほしいときは「文字だけ」 |
| 文字コード | ふだんは **UTF-8**。読み込んだ先で文字化けするときだけ **Shift_JIS** |
| 書類の言語 (メニュー「設定」) | 縦書きの書類は「日本語（縦書き）」 |
| 横向き・逆さまのスキャンを自動で直す (メニュー「設定」) | ふだんはオンのまま |

設定は次に起動したときも残っています。

## 6. 困ったとき

| こうなった | こうする |
| --- | --- |
| 「Tesseract (文字認識エンジン) が見つかりません」 | ScanText フォルダの中に `tesseract` フォルダがあるか確認。なければ、フォルダをもう一度まるごとコピーし直す |
| 「言語データが入っていません」 | 同上 (フォルダが欠けています) |
| 状態が「エラー: ファイルを開けません」 | ファイルが壊れているか、スキャンの途中で保存されたもの。もう一度スキャンする |
| 「パスワード付きの PDF は開けません」 | パスワードを外した PDF にしてから読み込む |
| 「対応していないファイル形式です」 | JPG か PDF でスキャンし直す |
| 文字がほとんど読めていない | スキャナを **300dpi・グレー (または白黒)** にしてスキャンし直す。傾きや影が少ないほどよく読める |
| 表の列がずれる | 表 (.csv) は、列が左揃えの表ほどきれいに分かれます。ずれたところは Excel で直す |
| メモ帳や Excel で文字化けする | 「文字コード」を切り替えて、もう一度「文字起こしを開始」 |
| 形式を変えてもう一度保存したい | 形式を選び直して「文字起こしを開始」→「もう一度文字起こししますか？」で「はい」 |
| 処理を止めたい | 「中止」 |
| 一覧からファイルを外したい | 選んで「リストから外す」(ファイル自体は消えません) |

それでも直らないときは、**エラーの文**と**どんな書類だったか**を控えて連絡してください。
(**書類の画像そのものは持ち出さないでください**)
