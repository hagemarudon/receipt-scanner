# スキャン文字起こし (ScanText)

スキャンした書類 (JPG・PDF など) から文字を読み取り、**.txt / .csv / .pdf** で保存する Windows アプリです。
**インターネットに一切つながずに動きます。** 電子カルテが入ったオフラインの PC でそのまま使えます。

- 読み取れるファイル: JPG / PNG / TIFF / BMP / PDF (複数ページ可)
- 保存形式 (画面で選択):
  - **テキスト (.txt)** … 読み取った文章。メモ帳で開けます。
  - **表 (.csv)** … 横に並んだ項目を列に分けて保存。Excel で開けます (検査結果の表など)。
  - **PDF (.pdf)** … 「元の画像＋文字」(見た目はそのままで、文字の検索・コピーができる) か「文字だけ」を選べます。
- 複数ファイル・フォルダをまとめて処理できます。ドラッグ＆ドロップにも対応。
- 横向き・逆さまにスキャンしたページは自動で向きを直します。
- 読み取った結果は画面で確認でき、「コピー」で電子カルテに貼り付けられます。

## 電子カルテ PC への入れ方

> 電子カルテ PC にソフトを入れてよいかは、病院のルール (システム担当の方) に先に確認してください。
> このアプリは通信をしませんが、USB メモリの持ち込み自体が禁止されている場合があります。

1. **ネットにつながる PC** で、このリポジトリの GitHub の「Actions」→ 最新の `test-and-build` → **ScanText-windows** をダウンロードして展開します。
   (自分でビルドする場合は、下の「自分で exe を作る」を参照)
2. 展開した **ScanText フォルダごと** USB メモリなどで電子カルテ PC にコピーします (デスクトップや `C:\ScanText` など)。
3. フォルダ内の **ScanText.exe** をダブルクリックで起動します。インストール作業は不要です。

フォルダの中身:

```
ScanText\
  ScanText.exe      ← これを起動
  _internal\        ← アプリ本体 (消さない)
  tesseract\        ← 文字認識エンジン Tesseract と日本語データ (消さない)
  settings.json     ← 設定 (初回終了時に作られる)
```

## 使い方

1. 「ファイルを追加…」(または「フォルダを追加…」、ドラッグ＆ドロップ) で書類を選ぶ
2. 「出力」で形式・保存先を選ぶ (設定は次回も引き継がれます)
3. 「文字起こしを開始」
4. 一覧のファイルを選ぶと下に結果が表示されます。ダブルクリックで保存したファイルを開けます。

保存先に同じ名前のファイルがあるときは上書きせず「名前 (2).txt」のように別名で保存します。
PDF を PDF で保存するときは元のファイルを消さないよう「名前_文字起こし.pdf」になります。

### 設定の補足

| 項目 | 説明 |
| --- | --- |
| 文字コード | 通常は **UTF-8** のまま。古いソフトに読み込ませて文字化けするときだけ **Shift_JIS** に。Shift_JIS で表せない文字 (一部の旧字体など) は「?」になります。 |
| 書類の言語 | 縦書きの書類は「日本語（縦書き）」に。 |
| Tesseract の場所 | 通常は自動で見つけます。見つからないときはメニュー「設定」→「Tesseract の場所を指定…」で `tesseract.exe` を選びます。 |

### きれいに読み取るコツ

- スキャナの解像度は **300dpi** (細かい字が多いときは 400〜600dpi)、カラーよりも **グレー** か **白黒** がおすすめです。
- 傾き・影・しわが少ないほど精度が上がります。
- **手書きの文字はほとんど読めません。** 印刷された文字向けです。
- 読み取り結果は必ず目で確認してから使ってください (数字の 1 と l、0 と O などを間違えることがあります)。

## 自分で exe を作る (開発者向け)

ネットにつながる Windows PC で:

1. [Python 3.10 以降](https://www.python.org/) と [Tesseract (UB Mannheim 版)](https://github.com/UB-Mannheim/tesseract/wiki) を既定の場所にインストール
2. このリポジトリのフォルダで `build_windows.bat` を実行 (日本語データ `jpn` / `jpn_vert` も自動でダウンロードします)
3. できた `dist\ScanText` フォルダを持っていく

開発・テスト:

```
pip install -e ".[dev]"
python -m scantext                                  # 画面を起動
python -m scantext --cli 書類.pdf -f csv -o 出力先   # コマンドで処理
pytest                                              # テスト (Tesseract がなければ OCR のテストは飛ばされます)
```

テストの方針は [docs/TEST_PLAN.md](docs/TEST_PLAN.md) にまとめています。
